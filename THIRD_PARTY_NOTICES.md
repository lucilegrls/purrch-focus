# Third-party software

Purrch uses React (MIT), Vite (MIT), Capacitor and its official plugins (MIT), and Lucide (ISC). Their license files remain in their npm packages. The complete pinned dependency graph is in package-lock.json.

Nunito and Lora variable fonts are redistributed through Fontsource under the SIL Open Font License 1.1. Their licenses are included in `public/licenses/` and are bundled with the app.

The watercolor room, tabby states and app icon were generated for this project using built-in OpenAI image generation from the user’s visual direction. Original outputs and prompts are retained in `artwork/`. User reference photographs and illustrations are not included. The alternative simple SVG room was drawn for this project. Ambient audio is generated locally from noise; no third-party sound recordings are included. No Cat on Chair artwork, code, branding or audio is included.
